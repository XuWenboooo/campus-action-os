# AI pipeline

The implemented local pipeline uses a unified file extractor: direct text and HTML are normalized locally, PDF text layers are extracted with PyMuPDF, scanned PDFs are detected and rendered into the OCR path, and PNG/JPEG images use the same OCR boundary. `LocalRapidOcrProvider` invokes the offline `rapidocr_onnxruntime` runtime without production credentials; `OcrProvider` remains injectable for controlled adapters and explicit failure tests. The parser provider boundary has `RuleBasedProvider`, `ExternalProvider`, and `FallbackPolicy`; external results are request-ID checked, schema/evidence/Error-Shield validated, retried only for infrastructure/rate-limit failures, and safely logged without source text. The pipeline separates lines, extracts audience/actions/deadlines/materials/location/platform, binds each explicit field to source evidence, verifies that evidence text occurs in the normalized source, constructs a sequential Action Graph, runs `Error Shield`, validates the response, and emits `succeeded` or `needs_confirmation`. Uploaded media bytes are persisted in `document_files` and checked against their declared PNG/JPEG/PDF signature. Unknown, ambiguous, malformed, encrypted, empty, unsupported, timeout, and unavailable inputs remain explicit failures; no live provider or credentials are used.
