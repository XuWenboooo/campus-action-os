# AI pipeline

The implemented local pipeline standardizes text, converts simple HTML to text, accepts an injected auditable `OcrProvider` for media, separates lines, extracts audience/actions/deadlines/materials/location/platform, binds each explicit field to source evidence, constructs a sequential Action Graph, runs `Error Shield`, validates the response, and emits `succeeded` or `needs_confirmation`. Uploaded image/PDF bytes are persisted in `document_files` and passed to the OCR boundary; the default provider returns an explicit `OCR_NOT_CONFIGURED` degradation and never treats media bytes or placeholders as parsed text. Unknown or ambiguous time values remain `null` with `precision=unknown`. No live provider or credentials are used.
