# Annotation guide draft

这是 CampusActionBench 的开发草案，不是已冻结的正式标注集。每条样本使用稳定 `sample_id` 和 `source_group`，保留原始/规范化 OCR 文本、输入类型、版面信息、用户画像、行动图、关键字段证据、歧义、冲突、缺失信息和风险标签。

标注员按最小可执行行动拆分步骤；截止时间保留原文边界和精度，未知值使用 `null` 加 `unknown`，不得用常识补全。材料逐项记录，证据跨度使用 OCR 文本半开区间 `[start,end)`；条件和例外附着到受影响行动。相关性必须依据通知与给定画像，不能把未知判为相关。

正式标注需要两名标注员独立完成，再由仲裁员处理差异；所有 gold 修改追加 `change_history`。当前合成样例只用于协议、解析器和评测工具开发，不代表真实通知、授权数据或正式一致性结果。
