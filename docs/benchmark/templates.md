# Benchmark 合规模板

## 数据卡

- 名称/版本：
- 目的与非目的：
- 规模与划分：
- 来源类型、授权主体、授权记录：
- 真实/重构/合成比例：
- 人群与通知类别覆盖：
- 已知缺失、偏差与风险：
- 脱敏方法与检查人：
- 保留期限、访问控制、撤回流程：
- 变更历史、负责人、审核日期：

## 授权记录

`authorization_record_id`、来源机构/渠道（不得填个人身份）、授权范围、用途、有效期、撤回条件、存储位置、审核人、签署/凭证引用、状态（pending/documented/revoked）。

## 脱敏检查清单

- [ ] 姓名、学号、手机号、身份证号、邮箱已删除或不可逆替换
- [ ] 具体住址、精确个人轨迹、二维码/条码/账号已移除
- [ ] OCR、附件、文件名、EXIF、隐藏层和版本历史均检查
- [ ] 样例值明显虚构，未与真实个体可链接
- [ ] 复核人、日期、工具版本和例外均记录

## 数据变更日志

`change_id`、时间、操作者、样本/谱系、旧版本哈希、新版本哈希、变更原因、授权影响、标注影响、是否需要重算 manifest、复核人。
