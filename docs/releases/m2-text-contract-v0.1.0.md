# Campus Action OS M2 text contract v0.1.0

This is an M2 interface checkpoint, not an M2 feature release.

It freezes the request, document assessment, response, error, versioning, privacy, deterministic
development mock, fixture catalog, contract tests, E2E harness, and parallel-owner handoff
boundaries for the text notification vertical slice.

It does not include real AI, a database, WeChat miniapp business logic, product persistence, a
production deployment, or formal experiments. Mock and fixtures are synthetic development-only
artifacts and are not model output or research evidence.

M1 baseline: `m1-foundation-v1.0.1` at `5a0d4ad7d0e38dbf10e04fe987ac6957212f33c2`.
Shared package: `@campus-action-os/protocol@1.1.0`.
Manifest: `docs/releases/m2-text-contract-v0.1.0.manifest.sha256`.
