# Testing

Use `npm.cmd run typecheck`, `npm.cmd run check:miniapp`, `npm.cmd run test`, `npm.cmd run test:api`, `npm.cmd run test:e2e`, `npm.cmd run db:migrate`, `npm.cmd run format:check`, `npm.cmd run lint`, and `npm.cmd run scan:secrets`. The core API test exercises the real parser HTTP server, SQLite repository, confirmation boundary and task state machine; the stability E2E repeats the synthetic Document → ParseJob → VerifiedActionObject → confirmed Task → completed Task path 100 times. Completing a task and publishing a notice also require an explicit confirmation field. Error Shield tests intentionally cover missing evidence, unsafe deadlines, unsupported claims and side-effect blocking. The mini-program check is static syntax/manifest validation only; runtime behavior remains `MANUAL_VERIFICATION_REQUIRED` until verified in WeChat Developer Tools.
